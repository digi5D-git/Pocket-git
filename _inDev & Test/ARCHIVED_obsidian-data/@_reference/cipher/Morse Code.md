# Morse Code

Adopted worldwide, and an essential precursor to telecommunications, **Morse Code** is a communication system using short & long pulses[^1] to represent the letters of the alphabet.

> [!learn] Origins  
> Named after the American scientist who developed it, Morse Code, was created by **Samuel Morse** in the year **1835**

## How to Use the Morse Code Cipher

**Morse Code** assigns to each letter, digit, or punctuation sign, a unique *combination* of signals made of short & long impulsions, typically represented with a dot **.** & a dash **-**

When writing, each character code is separated by a **space** & each word by a **slash** (/). Sometimes characters can be separated by a slash & words by a double slash (//).
