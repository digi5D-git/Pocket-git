# Dual-Tone Multi-Frequency Code

Dual Tone Multi Frequency code, better known as **DTMF Code**, is a *combination* of sound frequencies emitted by the keys of a telephone keypad.

These emitted sounds can be used by **telephone servers** to either recognize a dialed number, or by **automated voice servers** to recognize which keys are typed by the user.

## How to Encrypt

**DTMF** codes are used by phones & can be used to substitute numbers with their sound wave frequency as described in the table below:

|          | `1209 Hz` | `1336 Hz` | `1477 Hz` | `1633 Hz` |
| -------- | --------- | --------- | --------- | --------- |
| `697 Hz` | **1**     | **2**     | **3**     | **A**     |
| `770 Hz` | **4**     | **5**     | **6**     | **B**     |
| `852 Hz` | **7**     | **8**     | **9**     | **C**     |
| `941 Hz` | **\***    | **0**     | **#**     | **D**     |
