# T9

**Text on 9 Keys**, or T9, is a predictive text method based on a dictionary, used in old keypad mobile phones, to type text on a *keypad* with only numeric keys.

> T9 had other proprietary trade names as well, such as,
> - iTap
> - XT9
> - LetterWise
> - WordWise

> [!learn] Origins  
> The patent for **T9** is from **1985** and was popularized with SMS texting on the 1st compatible GSM phones back in the late 90s, early 2000s. But today T9 has all but disappeared.

## T9 Encryption

T9 encryption replaces a letter by the corresponding key code on a numpad/keypad.

> [!danger] T9 NOT multi-tap  
> T9 is not to be confused with the multi-tap code
> 
> > multi-tap, which is the successive pressing of keys until the correct letter is achieved.

### T9 Ciphered

The ciphered message is made up of digits, any 1s or 0s can only code spaces or punctuation.

## Decryption

Decryption of **T9** is normally based on a dictionary containing all words previously encoded.

## Textonym

A **textonym** is a name given to words written in the same manner with *T9*

A textonym would be something like:  
`COOL` = `2665` = `BOOK`
