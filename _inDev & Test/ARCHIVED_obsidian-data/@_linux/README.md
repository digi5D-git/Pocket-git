# Linux Commands from "The Practical Linux Handbook"

Welcome to the Linux Commands repository! This collection is a companion resource to the book "The Practical Linux Handbook" by Vajo Lukic.

## Purpose

This repository serves as a quick reference guide for the Linux commands covered in ["The Practical Linux Handbook".](https://www.amazon.com/dp/B0CYXJNYNL) It's designed to:

1. Provide easy access to the commands discussed in the book
2. Offer a practical, hands-on resource for readers to experiment with
3. Serve as a refresher for those who have read the book

## Structure

The commands are organized into sections, mirroring the structure of the book:

- [Directory Navigation](1-directory-navigation.md)
- [Basic File Operations](2-basic-file-operations.md)
- [Data Processing](3-data-processing.md)
- [Disk Usage](4-disk-usage.md)
- [System Monitoring](5-system-monitoring.md)
- [Network Operations](6-network-operations.md)
- [Text Processing](7-text-processing.md)
- [Compression/Decompression](8-compression.md)
- [Permission & Ownership](9-permissions-ownership.md)
- [Environment & System](10-env-and-system.md)
- [Secure Shell (SSH) and Secure Copy (SCP) ](11-ssh-and-scp.md)
- [Job Control](12-job-control.md)
- [Package Management](13-package-management.md)

Each section contains relevant commands with brief descriptions and usage examples.

## How to Use

1. Browse the sections to find the command you're looking for
2. Copy and paste the commands into your Linux terminal to try them out
3. Refer back to "The Practical Linux Handbook" for more detailed explanations and context
